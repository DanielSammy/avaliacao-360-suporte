Avaliação 360

Tutorial do Usuário

Este documento descreve como usar as funcionalidades do sistema. Use-o como guia rápido para avaliadores, gestores e administradores.

1. Login

  • Acesse a aplicação com suas credenciais. Se não tiver, solicite a um administrador.
  • Após o login, um token de sessão é salvo localmente para manter sua conexão ativa.

2. Visão Geral (Dashboard)

  • A página inicial exibe contadores rápidos do sistema: operadores, critérios e avaliações.
  • Use o menu central para navegar entre as seções de avaliação, relatórios e configurações.

3. Avaliar Operadores

Como Funciona

  • •O filtro de período (mês/ano) serve apenas para consulta. As avaliações são sempre salvas no mês corrente.
  • •Selecione um critério para exibir os operadores e preencha os valores correspondentes.
  • •Após o preenchimento, clique em "Salvar" para registrar os dados.

4. Acompanhamento de Avaliações

  • Esta tela exibe o progresso das avaliações, mostrando o total esperado versus o total concluído.
  • O icone ao lado do titulo mostra quantidade de avaliação dadas até mesmo por quem não é avaliado, já o outro icone mostra a legenda de como funciona a contagem de avaliações recebidas
  • Atenção: a geração de relatórios pode ser bloqueada se o número de avaliações não for compatível com o esperado.

5. Relatórios e Geração de PDF

Verificação Prévia

Antes de gerar um PDF ou enviar por email, o sistema verifica os seguintes pontos:

  • •Se existem avaliações pendentes no período selecionado.
  • •Se a quantidade de critérios avaliados corresponde à de critérios ativos.

Falha no Envio de Email

Se ocorrer um erro, verifique as credenciais SMTP, o token de autenticação ou a disponibilidade do backend.

6. Configurações (Admin)

  • As telas de administração permitem cadastrar, editar e gerenciar Operadores, Critérios e Blocos.
  • Importante: se já existem avaliações no mês corrente, estas telas entram em modo somente leitura para garantir a integridade dos dados.

7. Teste de Envio de Email

Na tela Configurações → SMTP há um formulário para testar o envio de emails.

  • •Preencha os dados do servidor SMTP e salve.
  • •Informe um email de destino e clique em "Testar Envio".
  • •Diagnóstico: Erro 401 indica falha de autenticação. Erros de rede podem ser problema de host, porta ou credenciais.

Aviso de Segurança

Nunca exponha credenciais SMTP. O ideal é que o backend gerencie o envio usando credenciais armazenadas de forma segura.

8. Dicas & FAQ

Não consigo gerar o PDF, aparece aviso de pendências.

Vá em Acompanhamento de Avaliações e verifique se há avaliações pendentes ou se todos os critérios foram avaliados para cada operador.

Como diferenciar avaliação manual de importada?

Critérios importados têm um ícone de download. O valor aparece preenchido e o campo é desabilitado para edição.

Preciso alterar valores de meta que vêm da API.

Se o critério tem tipoCriterio = 2, o valor vem da importação. Alterar manualmente não é recomendado. Fale com o responsável técnico.
