Tutorial do usuário — Avaliação 360 (Suporte)

Este documento descreve, em linguagem simples, como usar as funcionalidades principais do sistema de avaliação. Use-o como guia rápido para avaliadores, gestores e administradores.

1. Login

Abra a aplicação no navegador e faça login com suas credenciais.

  • Se você não tiver credenciais, peça ao administrador para criar um usuário via painel de Operadores (administrador).
  • Após o login, o sistema armazena um token de sessão localmente; mantenha-o seguro.

2. Visão Geral (Dashboard)

A página inicial exibe contadores rápidos: número de operadores, critérios, avaliações e versão do sistema.

  • Use o menu de navegação para acessar as telas de avaliação, relatórios e configurações.

3. Avaliar Operadores

Tela principal para registrar avaliações dos operadores.

Como funciona

  1. O filtro de período (mês/ano) na tela é somente para consulta — ele permite ver avaliações de meses anteriores. As avaliações sempre são gravadas no mês corrente. Ou seja, mesmo que você selecione outro período apenas para visualizar, ao salvar uma avaliação ela será registrada no mês atual.
  2. Selecione o operador a ser avaliado. A lista de critérios aparecerá agrupada por bloco. Para cada critério ativo, escolha o valor correspondente.
  3. Alguns critérios são marcados com um ícone de importação — esses critérios são preenchidos automaticamente por import de dados (por exemplo, tickets). Nesses casos:
    • Você não pode editar manualmente o valor (campo desabilitado).
    • O sistema exibirá um ✓ quando houver qualquer avaliação (importada ou manual) para o critério no período atual.
  4. Após preencher, clique em "Salvar" para registrar as avaliações.

Notas importantes

  • Critérios importáveis são controlados pelo campo metaCalculo e só são editáveis pelo processo de import.
  • Se houver avaliações pendentes (não salvas) a geração de PDF/relatórios pode ser bloqueada até que sejam resolvidas.

4. Acompanhamento de Avaliações

A tela de acompanhamento mostra o progresso das avaliações por período e permite identificar pendências.

  • Veja o total esperado de avaliações (operadores ativos × critérios ativos) e quantas já foram completadas.
  • Use filtros por bloco, operador e período para encontrar avaliações incompletas.
  • Correção: se o número de critérios avaliados não bater com os critérios ativos, documentos/relatórios podem ser bloqueados.

5. Relatórios e geração de PDF

O sistema gera relatórios em PDF com a metodologia e dados de avaliação.

  • Antes de gerar o PDF (ou enviar por email), o sistema checa:
    • Se existem avaliações pendentes no período — se sim, a geração é bloqueada.
    • Se a quantidade de critérios avaliados é igual à quantidade de critérios ativos — se não for, também bloqueia.
  • Ao enviar por email, o backend realiza o envio. Se o teste de envio falhar, verifique credenciais (SMTP), token de autenticação e disponibilidade do backend.

6. Configurações e telas de administração

As telas de configuração permitem cadastrar e editar Operadores, Critérios e Blocos.

Operadores

  • Adicionar, editar, ativar/desativar e excluir operadores.
  • Quando existir qualquer avaliação no mês corrente, a tela de operadores fica visível mas em modo somente leitura (campos e ações de adicionar/editar/excluir desabilitados).

Critérios

  • Cadastrar critérios com: bloco, tipo, tipo de meta e valor (R$).
  • Se tipoCriterio = 2, o campo valorMeta é preenchido a partir dos dados da API/import — não altere manualmente.
  • Critérios importáveis exibem um ícone/tooltip explicando sua origem. Esses critérios aparecem também na tela de avaliação, mas não podem ser avaliados manualmente (campo desabilitado).
  • Se houver avaliações no mês atual, a tela de critérios também fica somente leitura.

Blocos

  • Gerencie níveis de pontuação por bloco. Em meses com avaliações existentes, a edição é bloqueada (somente leitura).

7. Importar Dados

O sistema suporta importação de métricas (por exemplo, número de tickets) que preenchem critérios automaticamente.

  • Use a tela de Importação para subir arquivos CSV/XLSX no formato esperado.
  • Após o processamento, critérios marcados como importáveis receberão valores automaticamente para o período importado.
  • Importante: verifique o relatório de importação para confirmar que os dados foram mapeados corretamente para operadores e critérios.

8. Teste de envio de email (Sistema)

Na tela Configurações → SMTP há um formulário para testar o envio de email.

  • Preencha SMTP Host, Port, User e Password e salve (valores são persistidos localmente).
  • Informe um email de teste e clique em "Testar Envio". O frontend envia uma requisição ao endpoint do backend (/api/email/send), que é responsável por conectar ao servidor SMTP e efetuar o envio.
  • Se o teste retornar erro 401, isso indica que o backend exigiu autenticação — faça login antes ou configure um token válido.
  • Se o erro for de rede (timeout) ou falha de conexão com SMTP, verifique host/porta/credencial e logs do backend.
Segurança: nunca publique credenciais SMTP em arquivos públicos. O ideal é que o backend faça o envio usando credenciais armazenadas de forma segura.

9. Dicas & FAQ

Não consigo gerar o PDF — aparece aviso de pendências

  1. Vá em Acompanhamento de Avaliações e verifique se há avaliações pendentes.
  2. Verifique se para cada operador ativo todos os critérios ativos foram avaliados no período.

Como diferenciar avaliação manual de importada?

Critérios importados apresentam um ícone (download/arquivo). O valor importado aparece preenchido e o campo é desabilitado para edição.

Preciso alterar valores de meta que vêm da API

Se o critério tem tipoCriterio = 2, o valor base da meta vem da API/import. Para alterar esse comportamento fale com o responsável técnico — alterar manualmente no frontend não é recomendado e pode ser bloqueado.

Onde os administradores configuram as regras?

As telas de administração (Operadores / Critérios / Blocos / Sistema) concentram a configuração. Lembre-se: se o período atual já tem avaliações, muitas ações ficam somente leitura para evitar inconsistências.
